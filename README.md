# clinical-llm-scientometrics
Reproducible, open-data scientometric analysis of large language models in clinical medicine (2019–2026)
Pre-registration: [OSF link — ]
Authors: Krishna Sai Vasireddy (ORCID 0009-0001-8230-9786);
Monika Rao Mandava (ORCID 0000-0002-2791-2865)

What this study does

Using only open data (OpenAlex) and open code, it measures two things about the
clinical-LLM literature: (H1) what share of empirically evaluated work tests whether
models generalize beyond a single setting, and (H2) how geographically concentrated
the research output is. Both hypotheses are evaluated against thresholds fixed in
advance in the registration. Everything else is descriptive.

Status

Pre-data. As of the seed-set commit, no OpenAlex query has been run and no corpus
records have been observed. The recall seed set (data/seed_set.csv) is committed
before harvest; its git commit date establishes that ordering.
